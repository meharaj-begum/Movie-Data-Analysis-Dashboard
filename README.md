# Movie Data Analysis Dashboard

## Project Overview

This project is an Excel-based Movie Data Analysis Dashboard created to analyze movie data and generate meaningful insights.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard

## Key Analysis

- Total number of movies
- Movie distribution by language
- Movie analysis by genre
- Movie trends
- Rating analysis
- Interactive dashboard filtering

## Dashboard

The dashboard provides an interactive view of movie data using KPIs, charts, and slicers.
